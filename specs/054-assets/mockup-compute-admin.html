Mockup annotations

Fidelity notes for the Current identity · form factor: desktop admin (≈1000–1080px), reflows to 1 column.

Fidelity basis

Cloned from the running app — static/tokens.css + static/app.css (spec-012). Palette, radius (6px), elevation, the 240px left-nav shell, chips, meters and the segmented consumer bars are the real component idiom.

Invented / net-new

Context-grouped discovery view (Screen B) is partly net-new: the app-model of grouping scripts by app-folder / compose-project / declared-app is drawn from concerns 049 & 053, which are not yet built. The "DECLARED" app context is a forward-looking sketch of 053's declared-app population.

Blueprint identity is invented for this mockup — an engineering-drawing skin (grid paper, hairline borders, drafting rail + title-block, mono ids). Not a shipped theme.

Stubs & substitutions

Brand fonts are substituted with system stacks — Iskeru's "Space Grotesk" display / "Inter" body approximated via system-ui + weight/letter-spacing; no web fonts are fetched.

Nav items (Monitor, Blueprints, Runs, MCP surface, Tokens, App key) are stubbed — only the three task screens route.

All data is fabricated; no backend, no fetch. Test-connection, search/filter, the approval gate and legend isolation are faked client-side happy paths.

The approval affordance models the real gate: an action goes DRAFT → PENDING_APPROVAL → APPROVED and only the UI approves — there is no approve tool on the MCP surface.
